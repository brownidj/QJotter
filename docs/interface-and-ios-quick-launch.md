For quick access on iOS, create a shortcut containing **Open App → QJotter**, then assign it to:

- **Action button — my first choice**, if your iPhone has one. Configure it under Settings → Action Button → Shortcut. [Apple’s guide](https://support.apple.com/en-gb/guide/shortcuts/apdfea15680b/ios)
- **Back Tap:** double- or triple-tap the phone’s back. Configure under Settings → Accessibility → Touch → Back Tap. [Apple’s guide](https://support.apple.com/en-mide/guide/shortcuts/apd897693606/ios)
- **Control Centre:** add a Shortcut control and select it, giving you swipe-and-tap access. [Apple’s guide](https://support.apple.com/guide/shortcuts/run-shortcuts-from-control-center-apd06a9201d4/ios)
